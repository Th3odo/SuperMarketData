Supermarket Sales Analysis

Project Overview
This project analyzes supermarket sales data to identify trends in customer behavior, branch performance, product profitability, and payment methods.

Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

Analysis Performed
- Data Cleaning
- Date & Time Conversion
- Feature Engineering
- Exploratory Data Analysis
- Data Visualization

Key Insights
- Highest performing branch
- Most profitable product line
- Most popular payment method
- Customer rating trends
